# Bengaluru Metro Analytics & Ridership Forecasting

## Project Status: In Progress

A full-stack data analytics project analyzing metro ridership patterns 
across Bengaluru's metro network using PostgreSQL, Python, and Power BI.

## Tools Used
- PostgreSQL, DBeaver
- Python (pandas, prophet)
- Power BI
- Git / GitHub

## Key Findings
- Network handles ~724,000 entries/day across 83 stations (Sep 2025)
- Kempegowda interchange accounts for 4.7% of total network ridership
- Weekday ridership is 28.9% higher than weekends — commuter-dominated demand
- PM peak (18:00–19:00) is the single busiest hour network-wide
- 7 anomaly days detected via z-score analysis
